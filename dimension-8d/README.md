# 🔮 DIMENSION-X • 8D Stereoscopic Pop-Out Visual Engine

An ultra-immersive web experience featuring mind-bending **3D / 5D / 8D images** that literally appear to burst right out of the screen using multi-layer depth, stereoscopic perspective parallax, and mobile gyroscope tracking.

---

## ✨ Features

- **Frame-Breaking 3D Pop-Out**: Characters, claws, wings, and cosmic flares break past the frame boundaries at `translateZ(60px)` to `translateZ(140px)` elevation.
- **Dynamic 3D Parallax & Glare**: Mouse movements dynamically tilt the matrix and cast realistic specular lighting glare.
- **Mobile Gyroscope Support**: Automatically tracks your smartphone's physical tilt angles via accelerometer for a true holographic viewing experience.
- **Interactive Dimension Modes**:
  - `3D POP-OUT`: Stereoscopic depth and floating telemetry HUD.
  - `5D HOLO`: Holographic scanlines, RGB chromatic aberration split, cyan/magenta edge glow.
  - `8D HYPER-WARP`: Canvas particle vortex tunnel with warp-speed streaks and pulsating energy.
  - `ANAGLYPH 3D`: Stereoscopic Red/Cyan 3D glasses mode.
- **Pop-Out Depth Multiplier**: Custom slider from `1.0x` (Standard) to `4.0x` (**OUT OF SCREEN! 🔥**).
- **8D Audio Synthesizer**: Web Audio API binaural spatial drone hum and warp frequency sweeps.
- **360° Lightbox Theater**: Fullscreen interactive 3D inspection modal with drag-to-rotate controls.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
